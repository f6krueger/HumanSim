# Modifiers

`sex_female.yaml` holds the female derivation rules. It is generated by `tools/build_sex_rules.py`;
edit that script, not the file. Hormone, genotype and drug modifiers come in later phases.

A modifier file looks like this:

```yaml
modifiers:
  - id: example_sex_ratio
    stage: sex            # sex | hormone | genotype | drug
    op: ratio             # ratio | offset | set
    effects: {body_mass: 0.82}
    when: {sex: female}
    status: unsourced     # referenced | unsourced | placeholder
    source_ref: null
    rule_type: anatomical # anatomical | scaling | physiological | hormonal | assumed_neutral
    note: ""
```

Rules: each parameter may have at most one sex rule per condition (checked by `humansim check`),
and a sex rule is skipped for any parameter that has a stored female value.

# Modifiers

`sex_female.yaml` holds the sex rules. It is generated by `tools/build_sex_rules.py` from the stored
male and female values; edit that script, not the file. Hormone, genotype and drug modifiers come in
later phases.

```yaml
modifiers:
  - id: example_sex_ratio
    stage: sex            # sex | hormone | genotype | drug
    op: ratio             # ratio | offset | set
    effects: {body_mass: 0.82}
    when: {sex: female}
    status: unsourced     # referenced | unsourced | placeholder
    source_ref: null
    rule_type: anatomical # anatomical | scaling | physiological | hormonal | assumed_neutral
    note: ""
```

Sex rules are written female = f(male) and used in both directions: forward for a female whose value
is not stored, inverted (ratio divides, offset subtracts) for a male whose value is not stored. A rule
never changes a value that is stored for the context sex. At most one sex rule per parameter
(checked by `humansim check`), and each ratio must match the stored pair (also checked).
